mobile prototype

This is a clickable front-end demo for a university navigation app that goes beyond Google Maps by guiding users to exact rooms, entrances, indoor routes, events, and live campus information.

Try: type T 1001, tap an event marker, toggle layers, then press Start navigation.

  • Outdoor-to-indoor route transition
  • Room search and destination popup
  • Event, toilet, entrance, socket and opening layers
  • Mock real-time status for openings and accessibility
